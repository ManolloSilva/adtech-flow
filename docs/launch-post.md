# AdTech Flow — v1.0 Launch Post

AdTech Flow is now v1.0: an open-source, in-browser simulator for programmatic
advertising auctions. Explore the ecosystem map, step through a full RTB auction,
configure floors/consent/latency, inspect OpenRTB payloads, and edit `buyer.js`
/ `seller.js` live in a Monaco-powered developer sandbox.

- Live demo: https://manollosilva.github.io/adtech-flow/
- Repo: https://github.com/manollosilva/adtech-flow

Feedback and contributions welcome.
