# MCP Server: AdTech Flow Diagnostics

This directory contains the Model Context Protocol (MCP) server configuration that allows external AI assistants and IDE agents to interact with AdTech Flow.

## Tools Provided
- `simulate_auction`: Run a programmatic auction with specified floor price and timeout.
- `inspect_openrtb_schema`: Query OpenRTB field definitions and constraints.
- `query_sellers_catalog`: Search for adtech entities in the curated `sellers.json` index.
