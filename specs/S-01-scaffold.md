# Spec: S-01 Scaffold Vite + React + TypeScript project in `frontend/`

## User Story and Intent
As a developer setting up AdTech Flow, I need a modern, fast, and type-safe frontend foundation so that I can build the Interactive Ecosystem Map and Animated Auction Simulator efficiently.

## Acceptance Criteria
- [ ] A new Vite + React + TypeScript project is initialized in the `frontend/` directory.
- [ ] The default Vite scaffolding is present (e.g. `package.json`, `tsconfig.json`, `vite.config.ts`, `src/`).
- [ ] The project runs successfully using `npm run dev`.
- [ ] The `frontend` directory does not have nested git repositories (it's part of the main repo).

## Component Scope and Data Model
- No specific UI components or data models are required yet. This is purely a scaffolding task.

## Edge Cases and Out-of-Scope Items
- Adding routing, state management, or styling frameworks (like Tailwind) is out of scope for this specific issue (will be covered in subsequent setup tasks like S-02 and S-07).
